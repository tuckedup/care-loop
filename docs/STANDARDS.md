# Standards alignment

CareLoop is a portfolio demo with synthetic data. It makes no compliance claims. This file maps
design choices to the public standards and vocabularies listed in docs/sources.md. Wording rule:
"HIPAA-aligned design, synthetic data". Never claim HIPAA compliance or EPCS certification.

| Area                   | Vocabulary / standard mirrored                                         | Where in CareLoop                                                       | Status                                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Medication orders      | FHIR R4 MedicationRequest (status, intent)                             | patient_med_list projection                                             | Partial (status values active/stopped only; intent is not modelled; not a conformant resource)                                                                     |
| Review queue           | FHIR R4 Task statuses                                                  | renewal_queue projection (QueueStatus), clinician queue                 | Done (requested, in-progress, completed only; vocabulary mirrored, not a FHIR Task resource)                                                                       |
| Audit                  | FHIR AuditEvent-shaped JSON; audit controls concept                    | audit_log, audit_view, /admin/audit                                     | Done (AuditEvent-shaped, tamper-evident hash chain, pnpm audit:verify; not a certification, not a conformant FHIR server)                                          |
| Follow-up task         | FHIR R4 Task (status requested)                                        | follow_up_tasks (visit_schedule), clinician visits page                 | Done (status requested only)                                                                                                                                       |
| E-prescribing messages | NCPDP SCRIPT names (NewRx, RxRenewal, CancelRx, RxFill, Status, Error) | mock pharmacy (src/app/api/mock-pharmacy/simulate.ts), outbox           | Done (SCRIPT-style names NewRx, RxRenewalResponse, CancelRx, Status, Error, RxFill as simplified JSON; no SCRIPT XML, no real network, no certification)           |
| Drug vocabulary        | RxNorm RxCUIs via RxNav (cached at seed time)                          | data/rxnorm-cache.json, formulary seed (src/infra/db/formulary-repo.ts) | Done (ingredient-level RxCUIs fetched once from RxNav and cached; seeding works offline; TODO: source needed for dose-form-level RxCUIs)                           |
| Screening              | PHQ-9, GAD-7 scoring bands                                             | src/domain/rules/scoring.ts, R07 item 9, R08 total                      | Done (PHQ-9 and GAD-7 totals and bands; GAD-7 has no escalation rule in SPEC section 4, so it does not change the outcome; TODO: clinical review of a trigger)     |
| AI evaluation          | CREOLA hallucination/omission taxonomy                                 | evals/judge-eval.ts, src/ai/judge.ts (eval only), evals/judge-cases     | Done as a CREOLA-style fixture judge (major/minor definitions are this repo's simplification; hand-written fixtures, no live judge run; not a CREOLA reproduction) |
| AI transparency        | CHAI applied model card                                                | docs/MODEL_CARD.md                                                      | Done as a CHAI-style model card (own structure; not a CHAI-issued label or certification)                                                                          |

Non-goals: no real e-prescribing network, no EPCS, no real PHI, no drug-interaction checking.
Status reflects what exists in the repo; "Done" means the vocabulary is mirrored as described, never that a standard is conformed to or certified.
